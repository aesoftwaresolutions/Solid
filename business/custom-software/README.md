# Custom software

**Business line in Solid:** `Custom software`

## What it sells

Proprietary software built to a client's specification — internal tools, integrations and web applications
the client owns or licenses.

## How its money is tracked

| Money | Solid account (Schedule C template) | Business line |
|---|---|---|
| Milestone and project invoices | 4010 Sales and Service Revenue | Custom software |
| Contractors hired for one project | 6040 Contract Labor | Custom software |
| Licences or cloud resources bought for one project | 5010 Purchases and Materials | Custom software |

Contractor payments also count toward 1099-NEC tracking in Solid — record the contractor as a vendor.

## What belongs in this folder

- `playbooks/` — discovery, statement-of-work and hand-over checklists, written generally.
- `templates/` — a blank statement of work and change-request form.

Not here: a client's specification, source code, contract or credentials. Client code lives in its own
private repository.
